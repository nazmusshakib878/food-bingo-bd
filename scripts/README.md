# Script utilities

These scripts are maintenance tools and are not needed to run the app.

- `build-map.mjs` — builds map data.
- `verify-map.mjs` — validates map data.
- `download-wiki-images.js` — image research/download helper.
- `download-images.js` — legacy image search helper.
- `legacy/patch-lang.mjs` — archived one-off language migration script.

Run scripts from the repository root so their relative project paths resolve correctly.
